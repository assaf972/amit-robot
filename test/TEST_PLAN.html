📋 1. Overview

This document describes the comprehensive test plan for the line-following rescue robot built for the RoboCup Junior Rescue Line 2026 competition. The tests are implemented in AUnit (an Arduino-native testing framework) and cover all code layers from pin configuration through competition-level integration.

Test file: test/robot_test.ino

🔧 2. Testing Framework & Tools

ToolPurpose
AUnit (Brian T. Park)Arduino-compatible xUnit testing framework. Install via Arduino Library Manager.
Arduino IDE / CLICompile and upload test sketch to the board
Serial Monitor (9600 baud)View test results (PASS / FAIL / SKIP for each test)
Physical test fixturesBlack electrical tape on white surface, green markers (25×25 mm), obstacles, ultrasonic targets

How to Run

  1. Open Arduino IDE → Sketch > Include Library > Manage Libraries → search "AUnit" → Install.
  2. Open test/robot_test.ino.
  3. Select the correct board (Arduino Mega) and port.
  4. Upload to the robot.
  5. Open Serial Monitor at 9600 baud.
  6. Results print as each test runs: TestName | PASSED or TestName | FAILED.
⚠️ Safety Warning For motor tests, place the robot on a raised platform or remove the wheels. Motors will spin briefly during testing.

✅ 6. Bugs Fixed

✅ sharp_left() Direction

Was: both motors forward (wide curve). Now: left motor reversed — proper pivot matching sharp_right().

✅ PWM Overflow

Was: speed + 105 = 285 exceeded PWM max. Now: clamped with min(speed + 105, 255).

✅ Pin 13 Conflict

Was: pin 13 shared between ultrasonic trigger and LED. Now: LED moved to pin 8 (LED_PIN).

✅ Timer Overflow

Was: object_evation_timer as int overflowed after ~33 s. Now: unsigned long.

✅ Green Detection Logic

Was: R > L → right turned away from green marker. Now: comparison inverted (R < L) to turn toward green.
